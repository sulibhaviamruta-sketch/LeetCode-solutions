# Problem: Reverse String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

## Approach

I used the two-pointer approach to reverse the character array in place. One pointer starts from the beginning and another starts from the end. I swap the characters at these positions and move both pointers toward the center.

## Complexity

- Time: O(n)
- Space: O(1) auxiliary space

## Notes

I tested the solution locally with a normal string and a single-character edge case before submitting it to LeetCode.
